核查日期：2026-10-21。常读是业务数据上游；Vibbit 仅为产品参考，不作为数据源，不接入其账户或依赖其服务。

## 已确认与仍待确认

用户提供的 [常读上手指引](https://www.changdupingtai.com/sale/open-api-document?page=getting-started) 已包含服务端签名算法、分销商和渠道关系、分页响应结构及限流错误规则。本平台已据此实现签名读取、分页检查点、全局限流、独立剧库查询和失败恢复，详见 [CHANGDU_CATALOG.md](CHANGDU_CATALOG.md)。

本轮从官方文档页实际加载的公开资源取得完整接口元数据，确认端原生短剧／漫剧列表 `GET /novelsale/openapi/content/aweme_series/list/v1/` 和已有推广链 `GET /novelsale/openapi/aweme/promotion/list/v1/`，均标注业务类型 `19,20,21,22`。这证明接口定义存在，**不证明当前账号拥有权限或已经读取成功**。精确字段、来源与限制见 [公开接口研究记录](UPSTREAM_RESEARCH_2026-10-21.md)。

公开文档请求不需要登录或 Cookie。本轮没有读取浏览器会话凭据，没有创建推广链或发起广告。尚未提供常读 API 凭据，当前没有真实常读取数样本或线上响应时间证据。

## 应采用的抓取方式

1. **先核实账号权限。** 向常读取得对应端原生业务的分销商 ID 与 API 签名密钥。列表协议已内置，保存凭据后可启动只读抓取；不把网页账号密码当签名密钥。
2. **先验收一个只读样本。** 签名读取一页，将剧名、完整字符串 ID、集数和状态与已登录后台抽查对照。付费／免费字段未核实时显示未知，不由价格、剧名或状态推断。空列表只证明读取成功，不证明取得了剧目。
3. **拆开新剧同步与历史补齐。** 若上游有更新游标、最新排序／时间窗口或 Webhook，优先同步新上线和变化记录；历史剧库低优先级补齐。当前引擎尚未实现这两个独立队列，不能把全量重复扫描称为已经实现秒级新剧发现。
4. **在一个限流预算内调度。** 列表与推广链端点标注主管账号维度 3 QPS，通用限流错误说明建议降至 1 QPS 以下。当前仍保守采用全平台共用每秒最多一次及退避，不放大并发或规避限额。
5. **已有推广链单独同步。** 付费与免费分别记录，不能只按剧名合并。至少关联内容源／渠道、剧目 ID、业务类型和推广链 ID。读现有链接与创建新链接是不同操作；新建须有独立业务流程和防重复机制。
6. **视频下载使用独立队列。** 目录查询只传元数据；视频按授权 URL 有效期、带宽和体积下载，保存文件大小、内容哈希和来源。只有完成下载和文件校验后才能进入 M1 可生产素材包。当前目录行不代表视频已获得。
7. **由真实素材触发员工任务。** 成功保存的素材包交给 BXAGI 员工市场的岗位；由现有上传封存、生产规格、真实文件回收和审核流程继续处理。缺文件时等待，不生成虚假的可生产状态。

## 性能口径

- 1–2 秒目标适用于已同步剧库的列表／搜索响应；本地 SQLite 基准不等于生产网络端到端时延。
- 新剧发现时延应计算“上游可查询时刻 → 平台入库时刻”，依赖更新机制、排序、限流和后台执行器。尚无真实测试，不能给出已达标结论。
- 初次全量同步和视频下载单独计时。不得用异步排队成功、缓存返回或尚未完成的文件下载充当全量同步成功。
- 离页运行必须实际部署执行器并观察新鲜健康心跳。现有后台入口可用，不等于执行器已运行。

## 从 Vibbit 参考到本轮实现

[Vibbit 公开介绍](https://www.vibbit.cn/drama.html) 主要展示高光／钩子选段、批量组合、开头变体和包装流程；属于公开产品描述，未实际操作其登录后台。官网把投放数据反哺列为规划中，不能作为已完成的竞品闭环证明，也不采用其产能和效果宣传作为 BXAGI 验收指标。

本轮把“制作方案”落实到现有 M2：高光精剪、开头对照和卖点对照，预览各条成品的差异，再由用户明确应用为可编辑的制作要求。制作要求进入真实员工任务，沿原有规则冻结并记录在成品元数据中。方案预览不是已识别的高光时间点，也不是已经生成的成品。

保持现有每批 1–3 条限制。100 部 × 30 条须另外实现分批队列、并发资源控制、失败恢复与大文件处理，不能只放开前端数量。自动高光候选时间轴、模型质量评分和批量视频下载也未因本轮增加预设而视为已完成。

系统管理的“内容源”提供可下载的常读接入需求单，列出已核实接口和仍需确认的账号权限、时间格式、推广链归属及授权素材能力；需求单不包含账户、密钥或浏览器会话信息。
