# 八模块广告平台

本轮将原方案的 M1–M8 扩展为通用广告业务框架。业务层保存素材包、生产目标、预算、计划、数据和决策；能力层使用 BXAGI 官方市场员工执行素材生产和投放任务。用户只需 BXAGI 账号，不新增其他模型平台账号。

## 模块职责与当前实现

| 模块 | 已实现行为 |
| --- | --- |
| M1 原始素材管理 | 用户创建素材包并上传原始图片、视频、音频或文本；按上传批次保存，支持失败继续上传。上传不会自动派发生产，不依赖外部素材 API 或自动内容识别。 |
| M2 任务中心 | 按素材包选择生成 1–3 条图片或视频、比例、优化要求和自动/手动市场员工；用户明确开始生产；显示员工进度、等待原因及经营建议创建的优化任务。员工与大管家位于此模块的独立页签。 |
| M3 优化素材中心 | 只展示实际交付，按素材包和生产任务批次保留版本；支持预览、下载和审核。主成品与封面、说明等辅助文件分开，部分交付可以查看但不能用于投放。 |
| M4 投放中心 | 素材包投放工作区下包含多个独立投放单元，创建时默认选择该包可用主成品。包内表格显示每条素材的状态、预算、调整、消耗、曝光/转化与投产比；可进入单条详情。包级额度限制所有单元的预算分配，新增成品需明确加入投放。 |
| M5 数据中心 | 默认汇总整个工作区，按时间、渠道和素材包筛选，查看真实日报、趋势及素材表现；可定位 M4 的对应投放单元。缺失收入或转化不会当作零。 |
| M6 经营决策 | 基于已有素材及真实效果形成有依据的建议，记录采纳或暂不采纳。素材类建议创建待执行优化任务；预算类建议保存草案，不能仅因采纳就修改渠道预算。 |
| M7 系统管理 | 管理工作区昵称、通知邮箱和偏好、工作区名称、渠道凭证与连接检测。账号密码与身份仍由 BXAGI 管理；未开放的账号操作引导至官方入口。邮件偏好可保存，实际邮件发送尚未接通。 |
| M8 进化中心 | 分为素材创作指导和投放策略进化；保存方法假设、关联证据、验证、发布及回滚状态。已发布方法作为后续员工任务的参考，不自动取得预算、投放或生产权限。 |

首页为运营工作台，不计入八个业务模块。首页提供真实工作量、待处理事项、最近素材包和交付的快捷入口。旧员工入口保留兼容，统一进入 M2。

## 业务对象关系

- **素材包（project）**：一次商品、内容或服务推广的原始资料容器，长期保留包内原始文件。
- **输入批次（upload batch）**：一次已封存的输入快照。可以复用已上传文件并加入新文件；未完成上传不启动生产。
- **生产任务（job）**：绑定确定的输入批次和生产参数，包括成品数量、类型、比例与员工选择。同任务重复请求不会重复派发；补产创建新的生产任务并保留旧交付。
- **优化成品（creative）**：员工实际返回并归档的文件，记录来源任务与生产版本。主成品用于投放，封面、说明、字幕等作为辅助交付，不充当可投素材数量。
- **素材包投放（delivery group）**：基于原始素材包组织业务投放及共享预算。一个素材包可以保留不同批次和渠道的投放记录。
- **投放单元（campaign）**：新建流程中，一条主成品对应独立执行单元，保存渠道、账户、预算、执行状态及效果。历史多素材共享计划仍保留其原始口径，不把计划汇总虚构成单条素材数据。
- **日报与操作记录**：效果归属实际投放单元；包级及全局汇总复用同一批有效记录，避免重复累计。预算调整记录显示调整前后额度、执行者、原因和实际回执。

素材上传成功、员工接收指令、员工任务完成、成品归档、渠道接受投放和取得投放效果是不同状态，不能互相替代。

## 从建议到执行

M6 素材建议被采纳后生成持久化优化任务。用户从该建议进入 M2，可看到来源、优化要求和执行状态，再选择本次成品数量等参数并明确开始。服务端核实当前用户、已采纳决策与优化任务的关联；同一建议任务重试返回原执行记录。普通效果轮询不会擅自执行这类待确认的经营建议。

M8 的策略始终是 **advisory（提供参考）**。发布意味着将有记录的方法提供给后续员工任务，不意味着已证明商业收益，也不会绕过当前素材包预算、渠道授权或明确启动要求。M6 负责当前行动，M8 负责跨批次的方法沉淀。

## 上传、身份与运行边界

- 原始文件存储上限为每份 **64 MiB**；交给 BXAGI 员工以及回收单个成果的上限为 **16 MiB**。较大的原件可以保存，但开始优化前须压缩或分段，不能把“已上传”解释为“员工已接收”。
- 原始文件上传携带稳定请求 ID。响应丢失后的重试复用同一 ID，避免把已保存文件再次写入；完整上传并封批后才可显式生产。
- 项目、文件、任务、广告凭证、决策和策略按已核实的 BXAGI 用户隔离。密钥由服务端加密，保存凭证与连接验证成功是不同状态。
- 已有巨量引擎官方适配代码；实际执行仍需有效账户、接口权限、推广资产配置和转化回传。快手、腾讯等尚未全部完成官方适配。配置页面存在不代表渠道已可真实投放。
- 当前尚未配置用于验收的真实广告渠道，未发生本轮广告消费，也未验证真实投放到效果回传的完整闭环。
- 持久任务状态和后台执行器代码已实现，但演示环境的长期后台执行器尚未常驻。页面关闭后的持续生产跟进、报表同步和预算监测不能按已上线能力承诺。
- 投放总预算保护依赖渠道报表及暂停执行，存在回传延迟，不承诺即时零超支。员工调整不能超出用户授予的预算边界。
