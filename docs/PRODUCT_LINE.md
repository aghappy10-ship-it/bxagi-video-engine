# BXAGI 产品与产品线 2.2

BXAGI 是一个通用广告素材与投放工作区：上传业务素材，交给实际员工制作和优化，归档真实成品，设置预算，再以真实投放数据驱动下一轮素材。服装、短剧、游戏和其他业务共用这条流程，短剧是其中一个场景。

2.2 使用用户的 **BXAGI 实际账号及现有已雇佣员工**。员工目录、岗位和技能来自该账号；平台自动安排可用员工，不用本地角色名称冒充 AGI，不自动雇佣员工或续费。

## 产品模块

| 模块 | 用户操作 | 流程与交付 |
| --- | --- | --- |
| 素材生产 | 连接 BXAGI，上传原始文件，填写目标与真实卖点 | 从现有员工中安排生产任务，转交真实输入，显示异步执行状态；实际成品到达后才完成归档 |
| 素材管理 | 查看、下载、检查原素材与成品 | 按工作区账号和项目保存真实文件，保留来源、员工、任务及迭代版本 |
| 广告投放 | 选择成品，设置日预算、总预算和上限，连接广告账户并启动 | 先派发实际投放员工，其决策再经过预算与渠道工具检查；计划状态以真实渠道结果为准 |
| 效果优化 | 同步或录入真实效果，按需启用自动优化 | 更新去重快照，保护预算；数据充分时派发新素材实验，归档新增文件后等待下一轮真实效果验证 |

## 跨场景员工流程

| 业务素材 | 用户提供的依据 | 员工安排 |
| --- | --- | --- |
| 服装与商品 | 商品图片、视频、材质、款式和已确认卖点 | 从账号已有员工的岗位、描述与技能中安排商品素材和投放工作 |
| 短剧与内容 | 原片、字幕、内容说明及营销目标 | 安排账号已有的内容制作、剪辑或营销员工，能力以真实节点与交付为准 |
| 游戏 | 游戏截图、录屏、玩法事实及下载等目标 | 安排账号已有的游戏内容或营销员工，使用用户提供的事实制作素材 |
| 其他产品与服务 | 真实文件、业务说明、受众和转化目标 | 同一项目流程使用账号可用的员工；没有可用员工或权限时明确提示 |

行业名称不会自动赋予员工新的工具。视觉理解、剪辑、配音和渠道权限取决于实际账号、员工节点及接通能力。元数据场景判断不等于已经分析画面，员工文字回复也不等于已经产出文件。

## 一次完整使用

1. 直接登录 BXAGI，读取该账号现有员工；工作区数据按已验证 BXAGI 身份隔离，不按邮箱合并。
2. 新建项目并上传输入，当前员工转交上限为 **每件 16 MiB**。提供已确认的卖点后，平台派发对应实际员工任务。
3. 同步员工状态并接收专属任务目录内的真实 PNG、MP4 或文案文件。取得文件并通过技术与来源校验后进入素材库；仅有会话启动或完成文字时继续等待。
4. 选择实际成品，设预算并明确启动，交由投放员工及受控渠道工具执行。预算或渠道写入结果不明时先核对，不自动重发。
5. 使用真实效果开展下一轮。开启 `autoOptimize` 后，符合条件的素材任务由 bxagi-tick 后台周期选入和派发；新增成品的生成不代表已经证明效果提升。

## 持续运行与交付边界

后台员工同步与反馈派发需要实际部署、授权并运行执行器。预算监测另用独立周期，对所有活跃计划生效；关闭 `autoOptimize` 只关闭自动 ROI 调整和素材迭代，不关闭预算保护。报表和暂停存在延迟，总预算不是渠道原生硬限额。

原本地规则方案、浏览器排版和 FFmpeg 工具保留为独立工具或历史工作流。在 BXAGI 必需模式下，上游失败不会转成本地模板生成再宣称员工完成。真实员工需要人工确认或补充信息时，任务会等待处理。

巨量引擎适配代码已实现，执行仍需真实广告账户、素材及渠道参数验收；其他渠道以实际接入状态为准。网页只提供 BXAGI 登录，原有工作区数据仍需要有效 BXAGI 会话才能访问。代码支持独立 Cloudflare 部署；示例网址托管迁移与账号身份分离，不代表已经获得 BXAGI 官网服务器权限。

目前已交付接口、任务与成果归档流程及受控测试。**尚未完成真实 BXAGI 登录、现有员工的线上执行交付或真实付费投放验收**；这些结果需要用户实际账号和对应权限确认，不能由模拟接口测试代替。
