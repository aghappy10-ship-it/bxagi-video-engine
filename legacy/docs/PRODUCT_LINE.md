# BXAGI 视频生产与增长产品线

这套交付把原推介拆成三个可独立销售、共同使用同一工作台的产品。当前版本提供可运行的单节点 MVP；产品线中的待接能力有明确入口与交付条件，不作为已实现功能销售。

## 1. 产品定义

| 产品 | 使用者与任务 | 输入 | 当前输出 | 计量单位 |
| --- | --- | --- | --- | --- |
| **BX Studio · 素材生产** | 剪辑师、素材负责人：从长视频制作可复查的切片 | 原始视频、对应 SRT 字幕（导入或可配置本地 ASR）、片长与画幅要求 | 基于字幕的切片方案、本地预览草稿、队列任务、通过技术闸口的 MP4、校验与审计记录 | 原片分钟、任务数、成片分钟、存储量 |
| **BX Ads · 投放运营** | 投手、运营负责人：管理试投计划、依据数据调整预算 | 本地投放计划、实际消耗／收入／转化数据、ROI 目标与预算上限 | 计划台账、CSV 导出、保持／暂停／增预算／申请确认的建议及原因 | 账户数、计划数、数据更新量；广告消耗单列 |
| **BX Insight · 增长分析** | 制作负责人、运营分析师：检查计划表现、决定下一批内容 | 实际导入的投放数据、计划标识、生产与验收记录 | 基于现有数据的表现汇总、计划比较、生产证据、数据缺失提示 | 数据行数、分析周期、保留时长 |

### BX Studio 的当前边界

- **已实现：** 视频信息读取、SRT 解析、完整字幕句段选片、横版／竖版／方形输出、浏览器本地草稿导出、FFmpeg 服务端渲染、队列与任务状态、技术校验、任务下载与审计。
- **可配置、尚未真实推理验证：** 兼容模型 API 选片适配器、本地 faster-whisper ASR。默认关闭模型请求；没有供应商凭据、本地语音依赖或模型权重时明确不可用。当前测试覆盖本地模拟响应与确定性输出校验，实际质量、速度、费用须配置后实测。
- **待接入：** 视觉内容理解、因果链与反转识别、解说词生成、TTS／配音混音、成片语义质量验收、完整模型成本台账。默认选片是确定性规则，不能称为理解剧情；可选模型只提供待验收候选片段。
- **下载口径：** 服务端 MP4 通过句界与解码检查，表示满足当前技术条件；并不表示通过语义 AI 验收、版权检查、平台审核或人工内容验收。浏览器导出始终是待验收草稿。

### BX Ads 的当前边界

- **已实现：** 本地计划管理、实际指标录入／CSV 导入、预算纪律建议、数据陈旧与转化缺失保护、可追溯的本地记录。
- **待接入：** 巨量引擎、快手磁力、腾讯广告的正式账户授权、指标拉取、素材上传、计划创建、预算修改与回传校验。
- **执行口径：** 当前产生建议，不向广告平台发请求、不自动扣费。只有在平台正式授权、转化口径确认、操作审批与审计完成后，才交付实际执行能力。没有转化数据时，ROI 不按零计算。

### BX Insight 的当前边界

- **已实现：** 使用实际导入的数据展示消费与效果，缺失数据保留为空或明确提示。
- **待接入：** 素材 ID 与平台创意 ID 自动映射、跨平台统一归因、素材 DNA 标签、同口径 A/B 试验、转化延迟修正、可版本化的方法论库。
- **分析口径：** 观察到的相关性不能直接解释为素材带来的因果效果；归因能力在真实回传与素材标识贯通后验收。

| 组合 | 适用阶段 | 包含产品与交付 | 当前状态与升级条件 |

## 3. 当前生产流程

1. 导入用户有权使用的原片与对应 SRT；也可在配置本地语音依赖与权重后显式请求转写。服务端读取真实时长、尺寸与流信息，字幕与标点需复核。
2. 在片长约束内生成完整字幕段落的切片方案；素材不足时少出方案，不补造内容。可配置的模型规划只能选择原始字幕索引，时间取自原始字幕且须通过确定性校验。
3. 用户确认片段与画幅后，FFmpeg 真实渲染 MP4；任务及失败原因持久保存。
4. 句界、时间范围、成片可解码等检查通过后开放服务端下载。检查失败时保留失败记录并阻止正式下载。
5. 人工内容验收后投放；当前把真实报表导入工作台，查看预算建议与表现。

**当前技术闸口依赖 SRT 时间戳的准确性。** 字幕句段边界不保证台词识别正确、内容完整、叙事连贯或画面合适。语义验收未接入，因此原推介“全质量双闸”不能作为当前版本的交付承诺。

使用客户选定且有权使用的真实内容建立基线。若采用原推介的两周试产安排，应在开始前约定样本、检查项与账单口径；没有完成实测就不填写产能、成本或成功率。

| 项目 | 如何验收／计量 | 应保留的证据 |
| --- | --- | --- |
| 切片正确性 | 人工核对字幕时间；统计越界、句中切断与不合格方案 | 输入 SRT、方案、检查详情 |
| 成片可用性 | 全片解码检查；人工复查音画、可读性、片段意义 | MP4、FFmpeg 日志、人工验收结果 |
| 产能 | 在指定机器／分辨率／片长／并发下记录实际完成量；失败任务单列 | 机器配置、开始／结束时间、通过与失败任务数 |
| 成本 | 分开记录模型、计算、存储、流量及人工复核；按通过成片摊销 | 原始账单、资源使用记录、通过成片数 |
| 预算纪律 | 用陈旧数据、缺失转化、预算超限等案例确认建议与保护 | 输入指标、规则、建议、时间戳 |

## 5. 商业结算结构

客户报价应拆分以下项目，避免把模型调用费等同于全部生产成本。

| 费用项 | 结算依据 |
| --- | --- |
| 软件与服务 | 产品模块、部署环境、交付范围、维护与支持约定 |
| 模型调用 | 可选模型接口返回的实际用量（供应商未返回时留空）与原始账单；本版本不计算未经确认的费率或费用 |
| 计算资源 | 服务器配置、占用时长、并发与实际租用／自有成本 |
| 存储与带宽 | 保留容量、备份容量、实际下载与传输量 |
| 人工工作 | 内容复核、字幕修正、异常处理与运营工作 |
| 广告消耗 | 广告平台原始账单，与软件费和生产费分开 |

待试产得到可对账数据后，再确定单价、包量、超额规则与服务级别。本次不设未经验证的低价、保底 ROI 或产能承诺。

## 6. 部署与数据边界

- 当前服务为 **单租户 MVP**，API Token 是服务访问凭证，不是用户角色权限；没有 RBAC、多租户隔离或完整企业审批。
- 本地模式服务地址为 `http://127.0.0.1:8765`。外部绑定必须设置 `BX_API_TOKEN`；公开或团队部署还需要 HTTPS、网络访问控制与备份策略。
- 生产服务保存上传素材、字幕、任务、成片、计划与审计记录。浏览器工作区保存计划等状态，不持久保存所选原片字节；页面刷新后可能需要重新选择原片。
- UI 中的 API Token 只保存于当前会话，不进入工作区导出。备份工作区 JSON 不等于备份原片与服务端数据。
- 本次交付提供源码、静态工作台、生产服务、启动脚本、Dockerfile、API 契约、产品线说明与可选 AI 配置指南。广告平台、模型和第三方账户的开通、凭据与费用另行安排。
