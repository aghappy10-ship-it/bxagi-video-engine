# 交付验证记录

版本：MVP 1.1.0，2026-10-12。

## 已执行的检查

- 30 项 Node 规则、工作区和交互模块测试通过：句界、长字幕规划、无转化／陈旧数据、预算规则、恢复数据、日期口径、CSV 重复导入、七页模板和用户内容转义；新增参数保留、跨刷新偏好、路由、单次事件委托、请求超时／取消、旧请求保护及当前素材的流程状态。
- 26 项 Python 服务与模型适配测试通过：真实 HTTP、真实 FFmpeg、认证下载、失败关闭、重启恢复、Origin／Host 保护、模型返回校验与重定向保护；新增缺少依赖和持久化等待任务恢复检查。
- 独立延迟响应复核通过：旧素材上传／转写／规划和旧连接结果不能覆盖当前工作区。
- JavaScript／CSS 本地依赖图、静态服务 MIME 类型和两种后端启动方式通过。
- 11 组前后端预算建议一致性用例通过。
- 独立端到端验证通过：上传真实媒体文件 → 导入 SRT → 生成方案 → 合并两个完整句段 → 720 × 1280 竖屏 MP4 → 技术门禁 → 认证下载 → 全片解码。实测成片时长约 16.021 秒。
- 服务端字幕烧录专项用例验证后段字幕确实显示；缺少中文字体时拒绝中文烧录，避免输出乱码。Docker 配置包含 Noto CJK 字体。
- JavaScript 语法检查、Bash 启动脚本语法检查及实际 `start.sh --help` 通过。
- 部署包逐文件保留 SHA-256，ZIP 完整性检查通过。
- HTML、CSS 导入与结构检查通过；关键文字与背景颜色对比度至少为 4.82:1。此检查不代替实际浏览器布局检查。

测试素材为程序生成的动态测试图案及提示音，不是客户业务视频，也不是语音识别结果。下载原片与 SRT 后可自行验证；`dist/samples/verified_output.mp4` 为实际生成的成片，`verification.json` 为技术结果。

## 验证范围

服务端的两道技术门禁是字幕句界和媒体完整性。它们不替代语义 AI 审片、叙事质量审查、广告审核或内容效果验证。

模型适配器使用本地 HTTP 测试服务验证请求与返回处理，尚未调用真实付费模型；本地 ASR 的依赖与模型未安装，尚未执行真实转写。

浏览器视频播放／录制和视觉布局没有进行浏览器实机 QA；七页页面检查是 Node 模板与状态检查。Windows 启动脚本和 Docker 镜像没有在对应环境执行。

没有接入或操作实际广告平台，没有产生广告消耗；本版本不提供已验证的生产单价、日产能或 ROI 保证。
